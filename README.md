The objective of this analysis is to validate the 'Code Aster / SALOME' FEM results of a composite panel under bending moment. The approach used was to compare the FEM model stress output and compare it to the expected stress level according to the ASTM-D7249 standard. This ASTM code, Long Beam Bending test, is used to determine the panel skin tensile strength. This simulation, though, considerates an arbitrary load value, as only the panel geometry affects the stress. Material elasticity properties will only be needed to determine displacement, which is not the goal of this model, so bogus properties were used. THE MATERIAL PROPERTIES DO NOT REPRESENT A REAL MATERIAL. The '.ods' file sets the test parameters and has the expected stress hand calculation, the FEM stress results plot and the comparison between those values. The FEM results were found to be conservative for this sample dimensions, as the achieved stress was 5.08% higher than the theoretic value.
